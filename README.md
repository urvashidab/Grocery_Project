# Grocery Delivery Application

A full-stack grocery delivery application built as a production-oriented learning project. The application allows customers to browse grocery products, manage their cart, place orders, and track their order status.

## Tech Stack

Frontend

- React
- TypeScript
- Tailwind CSS

Backend

- Node.js
- Express.js
- TypeScript

Database

- PostgreSQL

Tools

- Git
- GitHub
- REST API
- Docker (if added)

Features

Customer

- User registration and login
- Browse grocery products
- Product categories
- Search and filtering
- Sorting
- Add products to cart
- Update cart quantities
- Place orders
- View order history
- Track order status

Admin

- Manage products
- Manage categories
- View customer orders
- Update order status
- Manage application data

Delivery Partner

- View assigned orders
- Update delivery status
- Manage active deliveries

Getting Started

Prerequisites

Make sure the following are installed:

- Node.js
- npm
- PostgreSQL
- Git

Frontend Setup

cd client
npm install
npm run dev

Backend Setup

cd server
npm install
npm run dev

API

The backend provides REST APIs for:

- Authentication
- Users
- Products
- Categories
- Cart
- Orders
- Admin operations
- Delivery operations
